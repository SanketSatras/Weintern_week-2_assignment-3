🛡 Security Architecture Highlights

• HttpOnly Cookie: Token cannot be accessed or stolen via JavaScript (mitigates XSS).
• Server-Side Verification: Backend verifies cryptographic HMAC signature on every request.
• Anti-Caching Headers: Browsers are instructed never to store protected profile payloads.
• Safe User Serialization: Password hashes are completely stripped before returning data.
